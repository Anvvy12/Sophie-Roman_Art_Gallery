# Чек-лист UI-review

## Сценарий

- Основное действие понятно без инструкции.
- Back/forward и прямой URL сохраняют состояние.
- Loading не вызывает лишний layout shift.
- Empty, no results и error предлагают следующее действие.

## Контент

- Украинский, русский и английский текст переносится.
- Длинное название не ломает карточку.
- Отсутствующий постер имеет стабильный fallback.
- Даты, числа и списки форматируются локалью.

## Responsive

- 320 px не имеет горизонтального overflow.
- Touch targets удобны.
- Фильтры не перекрывают результат.
- Grid сохраняет полезную ширину карточки.
- Desktop не растягивает строки чрезмерно.

## Клавиатура и assistive technology

- Все действия достижимы Tab/Shift+Tab.
- Enter/Space работают согласно семантике.
- Focus возвращается после закрытия dialog/popover.
- Заголовки образуют логичную структуру.
- Поля имеют labels, ошибки связаны с полями.

## Визуальная система

- Использованы theme/palette вместо случайных цветов.
- Spacing и radius повторяют существующий ритм.
- Hover, focus, active, disabled и selected различимы.
- Анимация необязательна для понимания результата.
