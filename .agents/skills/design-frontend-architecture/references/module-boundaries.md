# Границы модулей

Направление зависимостей: `App/routes → pages → domain components → ui`.

`providers`, `translation`, `styles` и граница данных не должны импортировать страницы.

Сигналы неправильной границы:

- компонент одновременно запрашивает, преобразует и рисует крупный экран;
- `ui` импортирует предметные типы фильма;
- состояние синхронизируется между URL, Context и локальным state;
- barrel-файл скрывает цикл;
- компонент получает много boolean-флагов для несвязанных вариантов;
- provider используется одним близким потомком.

Создавать абстракцию, когда контракт имеет несколько потребителей, повторяется поведение, нужно изолировать внешнюю систему или упростить тестирование.
