# Данные и состояние

| Вид данных | Владелец | Примечание |
| --- | --- | --- |
| Результат API | TanStack Query | Query key полностью описывает параметры |
| Фильтры каталога | URL search params | Сериализовать устойчивое состояние |
| Идентификатор сущности | Route params | Валидировать до запроса |
| Поля формы | React Hook Form | Схему Yup держать отдельно от JSX |
| Открытие popover | Локальный state | Держать рядом с trigger |
| Язык и тема | Существующий provider | Не создавать второй источник истины |

Разделять транспортную модель, нормализацию, внутреннюю модель UI и форматирование. Не делать поля обязательными, если источник этого не гарантирует.

Строить query keys от стабильных примитивов. Планировать инвалидацию по сущности и коллекции, а не глобально.
